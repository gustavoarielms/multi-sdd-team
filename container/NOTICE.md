# Runtime image notices

The runtime image source incorporates the official OpenAI Codex App Server
package version 0.154.0 for `aarch64-unknown-linux-musl` from the
`openai/codex` release `rust-v0.154.0`.

The upstream Apache-2.0 license and NOTICE are shipped under
`container/licenses/` and copied into `/usr/share/licenses/openai-codex/` in
the runtime image. No OpenAI credential, token, `auth.json`, or user state is
